# 토코 (toko)

Claude Code 프롬프트 위에 사는 픽셀 펫입니다. Claude가 일하는 동안 띠에서 숨 쉬고 걸어 다니다가, 작업이 끊긴 틈에 다가와 기지개 · 먼 곳 보기 · 물 한 모금을 권하고, 자리를 비웠다 돌아오면 하던 일을 한 줄로 짚어 줍니다. 목적은 AI와 일하며 쌓인 인지 부하를 덜고 숨을 돌린 뒤 일에 돌아가게 하는 것입니다.

토큰 수입은 로그 곡선이라 많이 쓸수록 덜 늘고, 쉬는 습관에 더 큰 보상을 줍니다. 업적 · 오늘의 퀘스트 · 집중 타이머 · 인카운터 도감으로 쉬는 습관을 모으고, 띠의 컨텍스트 · 비용 미터, `/memo` 생각 주차장, `/toko today` 오늘 요약으로 Claude Code를 조금 더 편하게 씁니다. `/bonk <이유>`로 Claude를 뿅망치로 때려 달라고 할 수 있고, 광장 서버를 설정하면 다른 사람의 펫과 손을 흔들고 함께 기지개를 켭니다.

설치 · 명령 · 광장 서버 설정은 레포 루트의 README를 보세요. `/toko help`로 명령 목록을 볼 수 있습니다.
